# 🏨 Smart HostelX Management System

A modern, SaaS-grade smart hostel intelligence platform designed to streamline hostel operations, student tracking, room allocation, complaint resolution, fee tracking, and visitor workflows in real-time.

🌐 **Live Demo:** [https://hostelx.onrender.com](https://hostelx.onrender.com)

---

## ✨ Features

### 🎓 Student Portal
* **Digital Onboarding & Profile Management:** Register with course, year, gender, and automated room preferences.
* **Leave Requests:** Apply for short-term/emergency leaves with a live preview and track approval status.
* **Room Transfer:** Raise and track requests for room changes with custom justifications.
* **Complaint System:** Raise, track, and resolve facility or personal grievances.
* **Fee Tracking:** Monitor payment history, dues, and transaction transparency.

### 🛡️ Warden / Admin Panel
* **Live Dashboard:** Real-time metrics on occupancy rates, total student counts, collected revenue, and pending dues.
* **Approval Workflows:** Seamlessly approve or reject room transfers, leave requests, and visitor permissions with visual photo verification.
* **Resident Management:** Full control over active vs. removed student databases, course metrics, and search capabilities.
* **Analytics & Visuals:** Integrated charts for financial distributions, ticket breakdowns, and category-wise utility statuses.

---

## 🛠️ Tech Stack & Architecture

* **Backend:** Python / Django Framework
* **Database:** SQLite (Lightweight file-based database)
* **Frontend:** HTML5, CSS3, JavaScript (featuring responsive dark-mode glassmorphism styling)
* **Hosting & Deployment:** [Render](https://render.com)
